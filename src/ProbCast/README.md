# ProbCast
ProbCast: AI-powered weather app for NASA Space Apps Challenge ("Will It Rain on My Parade?"). Uses NASA Earthdata (OPeNDAP, Giovanni, Data Rods, Worldview, Earthdata) + CPTEC/INPE for rainfall prediction, personalized chatbot advice (farmers/general users), interactive dashboards, maps &amp; exports. Built with Python &amp; Streamlit. 🌍☔
